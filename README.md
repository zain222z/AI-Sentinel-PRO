## 📋 نبذة عن المشروع

**AI Sentinel PRO** هو نظام ذكي ومتكامل لمراقبة الشبكات والخوادم، والتنبؤ بالأعطال التقنية قبل وقوعها. صُمم النظام خصيصاً لخدمة **إدارة جمارك صعدة** في الجمهورية اليمنية، ويهدف إلى تحويل أسلوب المراقبة من **التفاعلي (Reactive)** إلى **التنبؤي (Predictive)**.

حصل المشروع على **درجة امتياز** في مشروع التخرج بجامعة صعدة - كلية العلوم التطبيقية - قسم علوم الحاسوب.

| الميزة | الوصف |

## 🧠 آلية الذكاء الاصطناعي

### معاملات النموذج

| المعامل | القيمة |
|:---|:---|
| **الخوارزمية** | Random Forest |
| **عدد الأشجار** | 300 شجرة |
| **العمق الأقصى** | 15 |
| **عدد الميزات** | 10 ميزات زمنية |
| **حجم البيانات** | 47,631 سجل تدريبي |

### نتائج النموذج

| المقياس | القيمة |
|:---|:---|
| **الدقة (Accuracy)** | 98.8% |
| **معدل الاستدعاء (Recall)** | 100.0% |
| **الدقة (Precision)** | 94.1% |
| **F1-Score** | 97.0% |
| **زمن التنبؤ** | < 10 ملي ثانية |

### الميزات المستخدمة

1. **Latency** - زمن الاستجابة اللحظي (ms)
2. **CPU** - استخدام المعالج (%)
3. **RAM** - استخدام الذاكرة (%)
4. **Latency_diff** - تغير زمن الاستجابة
5. **CPU_diff** - تغير استخدام المعالج
6. **RAM_diff** - تغير استخدام الذاكرة
7. **Latency_rolling_mean** - المتوسط المتحرك لزمن الاستجابة
8. **CPU_rolling_mean** - المتوسط المتحرك للمعالج
9. **RAM_rolling_mean** - المتوسط المتحرك للذاكرة
10. **Latency_rolling_std** - الانحراف المعياري المتحرك

## 🚀 تشغيل النظام

### 1. متطلبات التشغيل

| المكون | الحد الأدنى |
|:---|:---|
| **نظام التشغيل** | Windows 10/11 |
| **المعالج** | Intel Core i5 أو أعلى |
| **الذاكرة RAM** | 8 GB كحد أدنى |
| **التخزين** | 20 GB مساحة فارغة |
| **الشبكة** | بطاقة Ethernet 1 Gbps |

### 2. تثبيت المكتبات

```bash
pip install -r requirements.txt
```

3. تشغيل النظام

```bash
# نافذة 1: تشغيل محرك المراقبة
cd src
python monitor.py

# نافذة 2: تشغيل الواجهة
cd src
streamlit run Dashboard.py --server.address 0.0.0.0 --server.port 8501
```

4. فتح النظام

افتح المتصفح على: http://localhost:8501

بيانات الدخول الافتراضية:

· اسم المستخدم: admin
· كلمة المرور: 123
